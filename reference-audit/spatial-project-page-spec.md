# Static project-page proof specification

Reference pages requested by the correction brief:

- <https://www.mariayablonina.com/mobile-robotic-fabrication-system>
- A second Maria Yablonina project page

The prescribed browser runtime reported no available browser backend, so neither page could be rendered, measured, or screenshot-compared. No computed project-page values are claimed.

The Charge Pavilion proof therefore establishes a deliberately separate project-page system while awaiting reference-side measurement:

- the same spatial name/Contact/Bio header relationship as the corrected homepage;
- a 1062px centered desktop canvas;
- 13px regular project title and 9.5px metadata;
- 11px body text in 225–280px blocks rather than a conventional wide article column;
- individually positioned media between 360px and 650px wide, always at intrinsic aspect ratio;
- text and media alternate laterally rather than forming one stacked blog column;
- credits and Back to Main remain small, spatially separated closing elements;
- all six existing Charge Pavilion images, captions, project text, credits, and the IAAC link are preserved.

This is the only migrated project-detail page in the correction proof. The remaining 15 project pages are intentionally not generated until the homepage and first project-page spatial systems can be reviewed against actual browser screenshots.
