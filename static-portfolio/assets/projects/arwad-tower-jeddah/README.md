## Source limitations and editorial basis

The supplied PDF is truncated: its linearization dictionary declares 92,623,543 bytes and 102 pages, but the file contains 44,113,202 bytes and lacks its final cross-reference table and page tree. A temporary recovery reconstructed 47 page records; missing resources prevent complete rendering of some pages. Only visually inspected usable figures were selected. The original PDF is not offered as a working public download.

Site appraisal, solar studies, buildable envelope, programme and office arrangements are supported by readable recovered pages. The year, team, parametric catalogue, Option 1 selection and phyllotaxis concept also draw on the existing `content/projects.js` project record. Terrace and panel descriptions are grounded in the supplied renderings. No individual role, completion status or quantified environmental savings have been invented. A complete PDF would allow the remaining presentation pages to be reviewed.

Reviewed project 3 in `project-references/NaitikPortfolio/Summer Portfolio-Naitik.pdf`, pages 11?12. This complete PDF directly supports the eight-option parametric catalogue, rapid data extraction and automated area/daylight comparison, selection of Option 1 for maximum BUA and atrium daylight, sublettable offices with adaptable partitions, the first two commercial floors, seasonal glass-panel radiation studies, and phyllotaxis-inspired shading.

The original truncated presentation remains unchanged; its limitation does not apply to this second PDF.
