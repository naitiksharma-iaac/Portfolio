Kerf bending reduces local timber-sheet stiffness by removing material where deformation is required. This project studies the reciprocal relationship between kerf geometry and the curvature that results from bending.

A parametric Grasshopper system generated kerf-pattern datasets, while regression models predicted bending radius and returned those predictions to the geometric workflow. Machine learning operates inside a computational-material feedback loop rather than after the design process.

Removing material to enable curvature

Repeated kerf cuts reduce local stiffness so that a relatively rigid timber sheet can form curved configurations. Kerf depth, tooth width, spacing, rotation, timber thickness and pattern geometry operate simultaneously and alter the final bending radius.

Four iterative datasets

Four dataset versions were developed, with each iteration responding to shortcomings in the previous one. Within this experiment, a parameter range of approximately 0–200 mm provided the most useful range for accurate prediction; it is not presented as a universal material rule.
