Origami Tree

Office
Hexagramm Design Pvt. Ltd.
Context
India Art Fair
Role
Computational development and fabrication documentation

Origami Tree translates a branching curve network into a triangulated folded surface assembled from labelled, fabrication-ready strips.

The workflow connects geometric development, component variation, sheet nesting, nomenclature and an internal metal support to the final built installation at India Art Fair.

Trunk and branch curves

A small set of curves representing the tree trunk and branches forms the input to a reusable Grasshopper workflow.

Organic branching as flat facets

The continuous mesh is triangulated so the curved organic form can be fabricated from sheet material as planar faces.
