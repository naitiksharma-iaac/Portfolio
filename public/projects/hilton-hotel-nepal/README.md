# Hilton Hotel, Nepal media

Put still images in `images/` and animated GIFs in `gifs/`. Suggested prefixes: `hero-`, `form-`, `facade-`, `rationalisation-`, `segmentation-`, `fabrication-`, `cnc-`, `mould-`, `construction-`, and `final-`.

Files are discovered automatically during `npm run build`. Use JPG, JPEG, PNG or WebP for stills and GIF for animations.
