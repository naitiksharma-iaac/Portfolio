# The Crown media

Place your original files in `images/user`, `gifs/user` or `video/user`. Reference assets, when available, live in the matching `reference` folders. A user file overrides a reference file with the same filename stem.

Useful prefixes: `hero`, `context`, `concept`, `petal`, `geometry`, `element`, `curvature`, `transition`, `parameter`, `grasshopper`, `optimisation`, `coordination`, `variation`, `catalogue`, `final`.
