# Arwad Tower, Jeddah media

Put still images in `images/` and animated GIFs in `gifs/`. Suggested prefixes: `hero-`, `catalogue-`, `massing-`, `option-`, `radiation-`, `environmental-`, `facade-`, `shading-`, `form-`, and `final-`.

Files are discovered automatically during `npm run build`. Use JPG, JPEG, PNG or WebP for stills and GIF for animations.
