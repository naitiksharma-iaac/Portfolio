# Project media

Each project has its own folder with `images`, `gifs` and `video` subfolders. Put your own files in their `user` folders and keep retrieved public-source assets in `reference`. Use a descriptive prefix followed by a number, for example `hero-01.jpg`, `process-02.png`, `growth-01.gif`, or `workflow-01.mp4`.

The website discovers supported `.jpg`, `.jpeg`, `.png`, `.webp`, `.gif` and `.mp4` files automatically at build time. A user file overrides a reference file with the same filename stem. The README inside each project folder lists useful prefixes for its case-study chapters.
