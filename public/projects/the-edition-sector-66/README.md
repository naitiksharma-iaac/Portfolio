# The Edition media

Place your original files in `images/user`, `gifs/user` or `video/user`. A user file overrides a reference file with the same filename stem.

Useful prefixes: `hero`, `context`, `language`, `facade`, `branching`, `geometry`, `balcony`, `coordination`, `parameter`, `grasshopper`, `optimisation`, `iteration`, `variation`, `catalogue`, `final`.
