# Configurable Topologies media

Put still images in `images/` and animated GIFs in `gifs/`. Suggested prefixes: `hero-`, `workflow-`, `typology-`, `dataset-`, `graph-`, `encoding-`, `training-`, `network-`, `accuracy-`, `loss-`, `result-`, `future-`, and `final-`.

Files are discovered automatically during `npm run build`. Use JPG, JPEG, PNG or WebP for stills and GIF for animations.
