# BioPol 3D Printing media

Put still images in `images/` and animated GIFs in `gifs/`. Suggested prefixes: `hero-`, `parameter-`, `test-`, `form-`, `component-`, `ml-`, `optimisation-`, `zoning-`, `toolpath-`, `fabrication-`, `prototype-`, and `final-`. Use `animation-` for motion files.

Files are discovered automatically during `npm run build`. Use JPG, JPEG, PNG or WebP for stills and GIF for animations.
