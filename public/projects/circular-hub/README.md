# Circular Hub media

Put still images in `images/` and animated GIFs in `gifs/`. Suggested prefixes: `hero-`, `pipeline-`, `passport-`, `clustering-`, `connection-`, `joint-`, `aggregation-`, `field-`, `application-`, and `final-`. Use `animation-` for motion files.

Files are discovered automatically during `npm run build`. Use JPG, JPEG, PNG or WebP for stills and GIF for animations.
